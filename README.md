# Python-choice-game-with-images

This is a text based adventure game based in an abandoned cabin.
There are images in the terminal for a more immersive experience.
Not every exit is safe..
Extremely user friendly.

Used:
if statements
methods
timed text

TO Install Chafa (images)
Windowswinget install hpjansson.Chafa
Windows  -  scoop install chafa
macOS  -  brew install chafa


TO RUN - All in terminal
1. Clone the repository: https://github.com/Cward00/Python-choice-game-with-images.git
2. cd Python-choice-game-with-images
3. python game.py
